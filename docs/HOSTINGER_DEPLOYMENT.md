# Hostinger Deployment

This project is a full-stack app:

- Frontend: React/Vite
- Backend: Python FastAPI
- Database: MongoDB
- Queue/cache: Redis
- Worker/scheduler: Celery and backend cron
- Reverse proxy: Nginx

Use a Hostinger VPS or Hostinger Web Apps plan that can run the backend services. A plain PHP/static shared hosting upload is not enough for the complete app because Facebook scheduling and publishing need the FastAPI backend, MongoDB, Redis, worker, and scheduler.

## Recommended Hostinger Setup

Use Hostinger VPS with Ubuntu 22.04 or 24.04.

Install Docker:

```bash
sudo apt update
sudo apt install -y ca-certificates curl gnupg git unzip
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo usermod -aG docker $USER
```

Upload the project ZIP to the VPS, then:

```bash
mkdir -p /var/www/ai-social-media-automation
cd /var/www/ai-social-media-automation
unzip ai-social-media-automation-hostinger-clean.zip
cp .env.hostinger.example .env
```

Edit `.env`:

```bash
nano .env
```

Required values:

- `PUBLIC_BASE_URL=https://your-domain.com`
- `FRONTEND_BASE_URL=https://your-domain.com`
- `ALLOWED_ORIGINS=https://your-domain.com`
- `JWT_SECRET` with a long random value
- `ENCRYPTION_KEY` generated by the command below
- `GEMINI_API_KEY` or `OPENAI_API_KEY`

Generate `ENCRYPTION_KEY`:

```bash
docker run --rm python:3.12-slim python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Start the app:

```bash
docker compose up -d --build
```

Check:

```bash
docker compose ps
curl http://127.0.0.1/api/v1/openapi.json
```

Open:

- `http://your-domain.com`
- `http://your-domain.com/docs`

## Domain Pointing

In Hostinger DNS, point the domain A record to your VPS public IP.

After DNS works, install SSL. If you use Cloudflare, set SSL mode to Full. If you want Let's Encrypt directly on VPS, add Certbot or place this stack behind Hostinger's supported SSL/proxy setup.

## Facebook Publishing Notes

For Facebook text-only posting:

- Add a Facebook Page account inside the app.
- Use a Page access token.
- Required Meta permissions commonly include `pages_show_list`, `pages_read_engagement`, and `pages_manage_posts`.

Never paste production tokens in chat or commit them to Git. Put them only in the app UI or server environment.

## Shared Hosting Warning

If you only upload `frontend/dist` to Hostinger File Manager, the dashboard may load but login, prompt generation, scheduling, and Facebook publishing will not work unless the backend is hosted separately and `VITE_API_BASE_URL` points to that backend.
